Known limitations
-----------------
- Phase 2 requires the central platform database to run on PostgreSQL.
- PostgreSQL credentials are supplied through Django database configuration and are not stored in BusinessDatabase.
- Asynchronous workers and production secret management are not implemented yet.
- Business-specific migration labels must be configured with BUSINESS_MIGRATION_APPS.
- Database cleanup after a partial external failure requires an operational retry/cleanup process.
